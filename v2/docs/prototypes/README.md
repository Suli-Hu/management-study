# Prototypes

静态产品样机放在这里，用来评审信息架构和交互流程，不代表最终实现代码。

## Stage 3 Discipline Admin

文件：

- `stage-3-admin-console-demo.html`

打开方式：

1. 在浏览器里直接打开该 HTML。
2. 评审重点：
   - 是否足够贴近当前 `/admin/disciplines`，不需要重新学习。
   - `+ 新建学科` 是否贴着“学科列表”模块，而不是全局按钮。
   - 学科信息、内容数量、负责人 / Token、编辑 / 删除是否在一行里更均衡。
   - 每行 `编辑`、空学科 `删除`、有内容 `含内容` 是否清楚。
   - “含内容不可删”的保护是否还保留。
   - Stage 3 新增的“线上立即生效 / 不需要 GitHub”提示是否够轻。
   - 点击负责人是否能进入“负责人分配”页；点击 Token 是否能进入“Token 管理”页。
   - 表单里是否只保留中文定位，不再出现多余的日本語一句标签栏。
   - 顶部返回是否应使用“返回”，而不是固定“返回首页”。
   - 列表里是否已经没有多余的中转按钮和状态筛选器。

说明：

- 这是纯静态 demo，不连接后端。
- 按钮只做列表、右侧管理页和删除确认演示。
- 视觉方向是沿用当前 v2 admin 页，做渐进式重构，不做大改版。
