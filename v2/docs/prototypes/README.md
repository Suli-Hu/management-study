## Stage 3 Admin Console

文件：

- `stage-3-admin-console-demo.html`

打开方式：

1. 在浏览器里直接打开该 HTML。
2. 评审重点：
   - Super Admin 首页是否能看清系统健康状态。
   - 学科详情页是否能解释 tenant / user / token 的关系。
   - Owner / Editor / Viewer 的角色语言是否清楚。
   - Token 创建后的 quickstart 是否够直观。
   - API Guide 是否能支撑学科负责人不走 GitHub。

说明：

- 这是纯静态 demo，不连接后端。
- 按钮只做页面切换和弹窗演示。
- 视觉方向是安静、高密度、运营后台，不是营销页。
