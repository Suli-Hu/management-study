Stage 3 样机

保留 v2 的三个后台场景：学科管理、用户权限管理、API Tokens。

MVP 原则： 不把权限和 Token 强塞进学科列表。学科列表只做学科元数据；权限继续用矩阵；Token 继续用全局创建和撤销流程。

不丢 v2 功能 线上立即生效 不需要 GitHub
