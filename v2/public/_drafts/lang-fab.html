组织变革 · 定义与4类型
Lewin · '47

变更组织构成要素（战略·结构·文化·流程）及其相互关系的活动。真实世界的变革通常是多类型复合发生而非单一类型——只改一维往往导致失败，需多要素综合推进。

必要性源于外部环境变化、战略-组织不匹配、组织存续需求三重压力。

4 种变革类型
1战略性变革：对事业领域和竞争优势源泉的重新审视。典型例：丰田 → モビリティカンパニー
2结构性变革：调整授权程度、部门编制、决策流程
3文化性变革：改变价值观、行为规范、共享假设
4流程性变革：重塑业务流程、信息系统、人事制度
5 个管理要点
1明确愿景
2高层领导力发挥
3沟通与卷入
4制度配套
5固化与持续

状态

操作行为

  • 拖动：在球上 pointer down → move → up，实时跟手；释放后球以弹性曲线吸附到最近的左/右边缘
  • 点击：累计移动 < 5px → 切换 zh ↔ ja，aria-pressed 同步
  • 记忆：吸附后 localStorage["lang-fab-pos"] 写入 { side: 'left'|'right', y: number }
  • 边界：上下夹在 [12, content_h - fab - 12]，左右 16px 留白
  • 触屏 + 鼠标 + 键盘：用 PointerEvent 统一；focus + Enter/Space 触发点击

到 v2 后的差异（仅说明，本 demo 不实施）

  • 定位 position: fixed（demo 用 absolute 因为父框是 phone）
  • 仅 @media (max-width: 1023px) 出现，桌面继续用 head-bar 内 chip
  • 只在 KP 有 body_ja 时挂载
  • bottom: max(18px, env(safe-area-inset-bottom))
  • 点击实际触发现有 [data-lang-toggle] click（保留 zh ↔ ja URL 切换语义）
