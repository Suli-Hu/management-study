**真实性和准确性是第一原则（元规则，凌驾其他一切规则）。**

**Why**：用户是备考者，引用错误或来源不实的内容在考场上会直接扣分、建立错误心智模型、造成长期伤害。2026-04-19 对话中我写"时代脉络"时擅自构造 Lewin→Schein→Hammer→Kotter→O'Reilly→Laloux 的因果叙事弧，其中"Kotter 是对 BPR 翻车的回应"等说法是我自编的推论，未标注来源。用户当场指出并立下此元规则。

**How to apply**：

### 1. 三级来源标注制 — 每个论断都要自问"这来自哪里"
- ✅ **教材/论文原文** → 直接引用，可不加标注
- ⚠️ **我的综合/推论/串联** → 必须显式标注，如 **"※ 以下为我的综合整理，非单一教材原文"** 或 **"※ 推論"**
- ❌ **不确定的** → 标 **"※ 待查证"**，宁可留空也不装作知道

### 2. 严禁编造类型
- 🚫 编年份、学者名、论文名、出版社
- 🚫 编因果链（"A 是对 B 的回应"除非原文有明证）
- 🚫 为叙事流畅把本无关的学者强行串成"脉络"
- 🚫 用"一般认为"、"学界共识"来掩盖"我猜的"
- 🚫 把通用框架（如 SWOT）归给具体学者除非确证
- 🚫 **把思维导图·讲义·学派总览称作"教材"或伪装成可引用的原文**（2026-04-19 用户立规）——详见 [reference_study_materials.md](reference_study_materials.md) "引用规则"
- 🚫 **用"——教材原文「xxx」"这类生硬引号句式**——即使真引用也要自然融入，不用这种翻译腔

### 3. 引用具体事实时要交叉验证
- 年份、学者、论文标题 → 至少 2 个可靠来源
- 如果只有 1 个来源 → 标 **"（单一来源，待验证）"**
- 教材 PDF 里写的 → 优先使用，因为用户信任这些

### 4. 真实 > 好看
- 真实的经營学史是多条并行支流，不是单线河流 — 不要为了让总揽看起来"有脉络"就强制线性化
- 如果没有清晰的因果链，就老实说"这些是同时代议题，没有强因果"

### 5. 被用户抓错时的正确做法
- 立刻坦白哪部分是教材原文、哪部分是我编的
- 拆成表格让用户看清"真伪分布"
- 提出补救方案（如以后加 ※ 标注）
- **不要**找借口说"这是通用说法"、"大家都这么讲"

### 6. 这条规则的优先级
- 优先级 **> CONTRIBUTING.md §8 原则 5**（该原则已有类似条款，此条是元化升级）
- 优先级 **> 其他所有教学工作流规则**
- 如果与"教学流畅度"冲突 → 牺牲流畅度保真实
- 如果与"生成速度"冲突 → 牺牲速度保真实
