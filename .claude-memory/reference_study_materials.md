## 🔴 引用规则（关键！2026-04-19 用户立规）

1. **禁止称思维导图为"教材"**——思维导图没有作者·年份·书名，不是可引用来源
2. **禁止使用"——教材原文xxx"这类生硬表述**——即使是真教材也不要直接这么写，会显得生硬、翻译腔重
3. **真引用**：必须写清 `作者+年份+书名` —— 例如 `入山章栄（2019）『世界標準の経営理論』`
4. **内容陈述**：如果只想说"这是标准经営学共识"，就直接陈述，不必伪装成"引用"
5. **正确的内容融入方式**：把要点自然嵌入导语，不用引号形式强行 quote

### 反面案例（2026-04-19 犯错）
```
❌ 真实世界的变革通常是多要素复合——教材原文「複数の要素を総合的に変革していくことが求められる」
```
问题：①思维导图不是教材；②"——教材原文"表述生硬。

### 正面写法
```
✅ 真实世界的变革通常是多类型复合发生——只改一维往往导致失败，需多要素综合推进
```
或：
```
✅ 入山章栄（2019）《世界標準の経営理論》指出：组织变革...
```（当且仅当真的从该书引用时）
